# ism3232-module10

## Mini-Project: Bella Beauty Salon Assistant

Bella is a mock beauty salon assistant that helps customers check existing appointments. It uses a separate AppointmentLookup tool to search a dictionary of sample client appointments. The assistant can respond to greetings, look up appointments, and provide a helpful response when it cannot identify a client. Requests to book, reschedule, or cancel appointments are handed off to a human salon team member because the mock assistant does not actually manage bookings. The conversation history stores user and assistant messages, but a real salon system would need to protect customer names and appointment information carefully.
